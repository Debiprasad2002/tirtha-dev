# Tirtha Frontend ↔ Backend Merge — Implementation Plan

Replace the server-rendered Django frontend of `tirtha-public` with the Vite + React 19
SPA from `tirtha-site/frontend/`, served by the existing `tirtha-public` Django project.
The reconstruction pipeline (AliceVision, VGGT, Celery workers, ARK identifier service)
is kept intact; only the user-facing view layer changes. The toy backend in
`tirtha-site/backend/` is discarded after cherry-picking the contributor email signals
and the `SiteSubmissionRequest` model.

Single origin. Session-cookie auth. DRF API. No CORS in production. Animated WebP
previews on hover, generated by a Playwright-driven Celery task.

## Preamble

### Goal

Production deployment serves the React SPA from
`https://smlab.niser.ac.in/project/tirtha/`, backed by a DRF API at
`https://smlab.niser.ac.in/project/tirtha/api/`. The existing reconstruction
worker, ARK service, admin, and email pipelines continue to work unchanged.
A new per-mesh animated WebP "hover preview" replaces the per-pin GIF that
currently hardcodes `/gifs/Rama Jai Shree Ram GIF.gif`.

### What exists today

| Repo | Role | Disposition |
|---|---|---|
| **TP** `tirtha_bk/` | Django 4.1 + Celery + AliceVision + VGGT + MANIQA + ARK + admin. Server-rendered templates. | Keep + extend. |
| **TS** `backend/` | Django 6.0 stand-in. `Site`, `ContributionBatch`, `ContributionImage`, `SiteSubmissionRequest`. Client-side GIS auth. Custom CORS middleware. Contributor approval/rejection email signals. | Discard. Cherry-pick: `SiteSubmissionRequest` model, contributor email signals, the GIS-token verification flow. |
| **TS** `frontend/` | Vite + React 19, Leaflet, three.js / `@react-three/fiber` / `drei`, i18n, ContributeModal, RequestSiteModal. | Keep. Move into TP `frontend/`. |

### Schema mismatch — the heart of the merge

| TS model | TP equivalent | Gap |
|---|---|---|
| `Site` (lat/lng/name/details) | `Mesh` (no lat/lng; has reconstruction params, runs, GS viewer config) | **Add lat/lng to `Mesh`** so the React map can render markers. |
| `Contributor` (`is_active=False`, approval required) | `Contributor` (`active=True`, no approval) | Change default to `False`; React/GIS flow assumes admin-approval. |
| `ContributionBatch` + `ContributionImage` | `Contribution` + `Image` | Names differ; semantics match. **Do not rename** TP models. |
| `SiteSubmissionRequest` | — | Port to TP. |
| — | `Run`, `ARK` | React side doesn't know about runs / persistent identifiers; new serializers expose them. |

### Architecture decisions (locked)

- **Single origin.** Django serves the built React app at `PRE_URL = "project/tirtha/"`.
  No CORS in production. Vite dev server uses CORS only during local development.
- **API style.** Django REST Framework. ViewSets + serializers + drf-spectacular for
  schema/docs.
- **Auth.** Client-initiated Google Identity Services → POST ID token → backend verifies
  → sets session cookie. The legacy `signin`/`verifyToken` authlib redirect flow is
  removed.
- **Approval.** `Contributor.active` defaults to `False`; admin approves via Django admin.
  Contributor-facing emails (approval/rejection/deactivation) are ported from TS.
  Admin notifications (existing `notify_admin_new_contributor`) stay as-is.
- **Home.** Empty map + pins from `/api/meshes/`; no auto-selection of a default mesh.
- **3D viewers.** `@google/model-viewer` for `aV` runs; `@mkkellogg/gaussian-splats-3d`
  for `GS` runs. One switcher component, see Task 43.
- **Hover previews.** Per-Mesh animated WebP at 512×512, generated by Playwright +
  Chromium offline, stored under `media/models/{ID}/published/{ID}__hover.webp`.

### Task 2 — Fix the `local_settings*` filename convention

**Files:** `tirtha_bk/tirtha_bk/{settings.py, local_settings.dev.py, local_settings.docker.py, local_settings.manual.py}`
**Depends on:** none
**Goal:** Make Python imports actually work without manual renames.

   ```

   local_settings.docker.py → local_settings_docker.py
   local_settings.manual.py → local_settings_manual.py
   ```
2. Update `tirtha_bk/settings.py`:
   ```python

       from .local_settings_dev import *
   else:
       # Production: copy local_settings_docker.py → local_settings.py at deploy
       # (or symlink); kept out of VCS so secrets aren't checked in.
       from .local_settings import *
   ```
3. Update `start-dev.sh` and the docker entrypoint to use the new filenames.
4. Update the top-of-file note in `local_settings_docker.py` to read:

### Task 3 — Settings security hygiene

**Files:** `tirtha_bk/tirtha_bk/local_settings_docker.py`
**Depends on:** Task 2
**Goal:** Fix three production settings bugs found during the walkthrough.

**Bug 3a — `SESSION_COOKIE_SECURE` gated on `GOOGLE_LOGIN`.** Current code at line 101:
```python

```

setups:
```python

    SECURE_PROXY_SSL_HEADER = ("HTTP_X_FORWARDED_PROTO", "https")
```

**Done when:** A request to `https://<host>/project/tirtha/api/meshes/` returns JSON

### Task 10 — Fix `Mesh.save` double-save + thumbnail recompression bug; sanitize `set_image`

**Files:** `tirtha_bk/tirtha/models.py:143-175, 262-266`
**Depends on:** none
**Goal:** Two latent bugs flagged in §11.

**Bug 10a — `Mesh.save()` re-resizes the thumbnail on every save** (verified in
code). Every contribution upload calls `mesh.save()` (`views.py:383`), which
reopens the thumbnail file, "resizes" (effectively no-op if already 400px),
re-saves at quality=60, then `super().save()` a second time. Repeated uploads
degrade thumbnail quality and double write amplification.

Replace lines 143–175 with:
```python
def save(self, *args, **kwargs):
    self.verbose_id = (
        self.country + "__" + self.state + "__" + self.district + "__" + self.name
    ).replace(" ", "_")

    # Detect whether the thumbnail file was actually (re)assigned this save.
    update_fields = kwargs.get("update_fields") or []
    thumb_changed = (
        self._state.adding
        or (not update_fields)             # full save with no update_fields hint
        or ("thumbnail" in update_fields)
    )
    # If caller passed update_fields and "thumbnail" isn't in it, skip the resize entirely.
    if update_fields and "thumbnail" not in update_fields:
        thumb_changed = False

    super().save(*args, **kwargs)

    if not (thumb_changed and self.thumbnail):
        return

    try:
        image = PILImage.open(self.thumbnail.path)
        image = ImageOps.exif_transpose(image)
    except Exception:
        return

    aspect_ratio = image.width / image.height
    min_dimension = 400
    new_width, new_height = image.width, image.height
    if image.width >= min_dimension and image.height >= min_dimension:
        if aspect_ratio > 1:
            new_width  = max(min_dimension, int(min_dimension * aspect_ratio))
            new_height = min_dimension
        else:
            new_width  = min_dimension
            new_height = max(min_dimension, int(min_dimension / aspect_ratio))
        # Only resize+recompress when we actually downsize.
        if (new_width, new_height) != (image.width, image.height):
            resized = image.resize((new_width, new_height))
            resized.save(self.thumbnail.path, quality=60)
            resized.close()
    image.close()
```

**Bug 10b — `set_image` filename split** at lines 262–266 uses
`filename.split('.')[-1].lower()`, which mis-handles dotless filenames
(returns the entire basename as "extension"). Replace with:
```python
def set_image(obj, filename):
    upload_to = f"models/{obj.contribution.mesh.ID}/images"
    _, ext = os.path.splitext(filename)
    ext = ext.lstrip(".").lower() or "bin"
    filename = f"{str(obj.ID)}.{ext}"
    return os.path.join(upload_to, filename)
```

**Done when:** Re-uploading the same contribution multiple times leaves the existing
thumbnail bit-identical (no quality degradation), and uploading a file named
`README` (no extension) is rejected by Task 9's validator with a clean error.

from rest_framework.response import Response
from rest_framework import status

def get_session_contributor(request):
    """Returns (contributor, error_response). Either contributor or response is None."""
    email = request.session.get("contributor_email")
    if not email:
        return None, Response(
            {"allow_upload": False, "message": "Authentication required."},
            status=status.HTTP_401_UNAUTHORIZED)

        contrib = Contributor.objects.get(email=email)
    except Contributor.DoesNotExist:
        request.session.pop("contributor_email", None)
        return None, Response(

    if contrib.banned:
        return None, Response(
            {"allow_upload": False, "message": "Account banned. Contact admin."},
            status=status.HTTP_403_FORBIDDEN)
    if not contrib.active:
        return None, Response(
            {"allow_upload": False, "message": "Contributor approval required.",
             "approval_required": True},
            status=status.HTTP_403_FORBIDDEN)
    return contrib, None

class MeshViewSet(mixins.ListModelMixin, mixins.RetrieveModelMixin,
                  viewsets.GenericViewSet):
    lookup_field = "verbose_id"
    pagination_class = None   # Map needs all rows; tens of meshes today.

    def get_queryset(self):
        latest_run_subquery = Run.objects.filter(
            mesh=models.OuterRef("pk"),
            hidden=False,
            status__in=("Archived", "Manual"),
        ).order_by("-ended_at").values("ID")[:1]
        return (Mesh.objects
                .exclude(hidden=True)
                .annotate(
                    _latest_run_id     = models.Subquery(latest_run_subquery),
                    _contribution_count = Count("contributions", distinct=True),
                    _image_count        = Count("contributions__images", distinct=True),
                ))

    def get_serializer_class(self):

        qs = self.get_queryset()
        if q:
            qs = qs.filter(
                Q(name__icontains=q) | Q(country__icontains=q) |
                Q(state__icontains=q) | Q(district__icontains=q))
        return Response(MeshListSerializer(qs, many=True).data)

from django.conf import settings
from django.views.decorators.csrf import ensure_csrf_cookie
from google.auth.transport import requests as google_requests
from google.oauth2 import id_token as google_id_token


@api_view(["POST"])
@permission_classes([AllowAny])
@throttle_classes([ScopedRateThrottle])
def google_login(request):
    request.throttle_scope = "google_login"
    token = request.data.get("token") or request.data.get("id_token")
    if not token:
        return Response({"status": "error", "message": "Token is required."}, status=400)

    client_id = settings.GOOGLE_CLIENT_ID or settings.OAUTH_CONF.get("OAUTH2_CLIENT_ID")
    if not client_id:
        log.error("GOOGLE_CLIENT_ID not configured")
        return Response({"status": "error",
                         "message": "Server misconfiguration."}, status=500)

    try:
        info = google_id_token.verify_oauth2_token(
            token, google_requests.Request(), client_id)
    except Exception as e:
        log.warning("Google token verification failed: %s", e)
        return Response({"status": "invalid_token",
                         "message": "Invalid Google token."}, status=400)

    email = info.get("email")
    if not email:
        return Response({"status": "error",
                         "message": "Google token missing email."}, status=400)

    name = info.get("name") or ""
    pic  = info.get("picture") or ""

    contrib, _ = Contributor.objects.get_or_create(
        email=email,
        defaults={"name": name, "active": False, "profile_picture": pic})

    dirty = []
    if name and contrib.name != name:
        contrib.name = name; dirty.append("name")
    if pic and contrib.profile_picture != pic:
        contrib.profile_picture = pic; dirty.append("profile_picture")
    if dirty:
        contrib.save(update_fields=dirty)

    request.session["contributor_email"] = contrib.email
    request.session.set_expiry(0)
    request.session.cycle_key()       # session fixation hardening

    status_str = ("banned"           if contrib.banned else
                  "approved"         if contrib.active else
                  "waiting_approval")
    return Response({"status":      status_str,
                     "contributor": ContributorSerializer(contrib).data})


@ensure_csrf_cookie
@api_view(["GET"])
@permission_classes([AllowAny])
def current_contributor(request):
    email = request.session.get("contributor_email")
    if not email:
        return Response({"status": "anonymous"})
    try:
        contrib = Contributor.objects.get(email=email)
    except Contributor.DoesNotExist:
        request.session.pop("contributor_email", None)
        return Response({"status": "anonymous"})
    status_str = ("banned"           if contrib.banned else
                  "approved"         if contrib.active else
                  "waiting_approval")
    return Response({"status":      status_str,
                     "contributor": ContributorSerializer(contrib).data})

@permission_classes([AllowAny])

    return Response(status=204)

from .emails import (send_contributor_approval_email,
                     send_contributor_rejection_email,
                     send_contributor_deactivation_email)


def _is_pending(active, banned):
    return not active and not banned


@receiver(pre_save, sender=Contributor)
def _capture_previous_contributor_state(sender, instance, **kwargs):
    """Capture previous (active, banned) so post_save can detect transitions."""
    if not instance.pk:
        instance._prev_active = None
        instance._prev_banned = None
        return
    prev = sender.objects.filter(pk=instance.pk).values("active", "banned").first()
    instance._prev_active = (prev or {}).get("active")
    instance._prev_banned = (prev or {}).get("banned")


@receiver(post_save, sender=Contributor)
def _contributor_status_email(sender, instance, created, **kwargs):
    if created:
        return
    prev_active = getattr(instance, "_prev_active", None)
    prev_banned = getattr(instance, "_prev_banned", None)
    if prev_active is None or prev_banned is None:
        return

    was_pending = _is_pending(prev_active, prev_banned)
    is_pending  = _is_pending(instance.active, instance.banned)

    # pending -> approved/banned
    if was_pending and not is_pending:
        if instance.banned:
            send_contributor_rejection_email(instance)
        elif instance.active:
            send_contributor_approval_email(instance)
        return

    # approved -> pending (admin deactivation)
    if prev_active and not instance.active and not instance.banned:
        send_contributor_deactivation_email(instance)

export async function fetchMeshes(signal) {
  const endpoint = `${getApiBaseUrl()}${MESHES_API_PATH}`;
  logApiCall(endpoint, 'GET');
  const res = await fetch(endpoint, {
    method: 'GET', headers: { Accept: 'application/json' },
    signal, credentials: 'include',
  });
  if (!res.ok) throw new Error(`HTTP ${res.status}: ${res.statusText}`);
  const payload = await res.json();
  const items = Array.isArray(payload) ? payload : payload.results;
  if (!Array.isArray(items)) throw new Error('Unexpected response');
  return items.map(normalizeMesh).filter(Boolean);
}

export async function fetchMeshDetail(vid, signal) {

  const res = await fetch(endpoint, { signal, credentials: 'include' });

  return res.json();
}

export async function searchMeshes(query, signal) {
  const endpoint = `${getApiBaseUrl()}${MESHES_API_PATH}search/?q=${encodeURIComponent(query)}`;
  const res = await fetch(endpoint, { signal });
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return (await res.json()).map(normalizeMesh).filter(Boolean);
}

export default function ArkResolver() {
  const { '*': ark } = useParams();
  const navigate = useNavigate();

  useEffect(() => {
    // ark format: "{naan}/{shoulder}{name}" or "ark:/{naan}/..."
    const cleaned = ark.replace(/^ark:\/?/, '');
    const [naan, ...nameParts] = cleaned.split('/');
    const name = nameParts.join('/');
    if (!naan || !name) { navigate('/', { replace: true }); return; }

    const url = `${getApiBaseUrl()}/api/arks/${encodeURIComponent(naan)}/${name}/`;
    fetch(url).then(async r => {
      const data = await r.json().catch(() => null);
      if (r.ok && data?.status === 'ok') {
        navigate(`/models/${data.mesh_vid}/${data.run_id}`, { replace: true });
      } else if (data?.fallback) {
        window.location.replace(data.fallback);
      } else {
        navigate('/', { replace: true });
      }
    });
  }, [ark, navigate]);

  return <div className="loading">Resolving ARK…</div>;
}

### Task 47 — Patch the existing nginx config

**Files:** `config/tirtha.docker.nginx`
**Depends on:** Tasks 23, 46
**Goal:** Preserve the existing unix-socket convention; add hover-preview cache
header.

The existing 37-line file uses bare `/static`, `/media`, error pages, and

handles the PRE_URL — nginx only needs to differentiate static vs. dynamic.

Patch:
```nginx
location /project/tirtha/static/ {
    alias /var/www/tirtha/prod/static/;
    autoindex off;
    expires 30d;
    add_header Cache-Control "public, immutable";
}

location /project/tirtha/media/ {
    alias /var/www/tirtha/prod/media/;
    autoindex off;
    # Hover previews — long cache, cache-busted via ?v=<ts> from API
    location ~* /models/.+/published/.+__hover\.webp$ {
        expires 365d;
        add_header Cache-Control "public, immutable";
    }
}

location /project/tirtha/ {
    include proxy_params;
    proxy_pass http://unix:/run/tirthad.sock;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 200M;
}

# Keep error pages and the eventual TLS redirect block as in the original file.
```

(The `return 301 https://...` at the bottom of the original file is a TLS

### Task 52 — Celery task `generate_hover_preview`

**Files:** `tirtha_bk/tirtha/tasks.py`
**Depends on:** Tasks 6, 49, 51
**Goal:** Render 24 frames, encode as animated WebP, save to `Mesh.hover_preview`.

Append to `tasks.py`:
```python
@app.task(bind=True, autoretry_for=(Exception,), retry_backoff=True,
          max_retries=2, queue="preview")
def generate_hover_preview(self, run_id: str, n_frames: int = 24,
                           size: int = 512, fps: int = 15):
    """Render `run_id` and store an animated WebP at Mesh.hover_preview."""
    import asyncio, io, pathlib
    from PIL import Image
    from django.utils import timezone
    from .models import Run

    async def _render():
        from playwright.async_api import async_playwright
        async with async_playwright() as p:
            browser = await p.chromium.launch(args=[
                "--use-gl=swiftshader",         # CPU-only; swap to angle if GPU
                "--disable-dev-shm-usage",
                "--no-sandbox",
            ])
            ctx = await browser.new_context(
                viewport={"width": size, "height": size},
                device_scale_factor=2,
            )
            page = await ctx.new_page()
            await page.goto(
                f"http://127.0.0.1:8000/{settings.PRE_URL}internal/preview-renderer/?run={run_id}",
                wait_until="networkidle", timeout=120_000,
            )
            await page.wait_for_function("window.__renderReady === true",
                                         timeout=120_000)

            frames = []
            for i in range(n_frames):
                deg = (i / n_frames) * 360.0
                await page.evaluate(f"window.__rotateTo({deg})")
                # Settle: enough for both branches. Tune per hardware.
                await page.wait_for_timeout(150)
                buf = await page.locator("#stage").screenshot(type="png")
                frames.append(Image.open(io.BytesIO(buf)).convert("RGBA"))
            await browser.close()
        return frames

    frames = asyncio.run(_render())
    if not frames:
        raise RuntimeError("no frames rendered")

    run = Run.objects.select_related("mesh").get(ID=run_id)
    mesh = run.mesh
    out_dir = pathlib.Path(settings.MEDIA_ROOT) / "models" / str(mesh.ID) / "published"
    out_dir.mkdir(parents=True, exist_ok=True)
    out_path = out_dir / f"{mesh.ID}__hover.webp"

    frames[0].save(
        out_path, format="WEBP", save_all=True,
        append_images=frames[1:],
        duration=int(1000 / fps), loop=0,
        quality=72, method=6, lossless=False, allow_mixed=True,
    )

    mesh.hover_preview = f"models/{mesh.ID}/published/{mesh.ID}__hover.webp"
    mesh.hover_preview_generated_at = timezone.now()
    mesh.save(update_fields=["hover_preview", "hover_preview_generated_at"])
    return str(out_path)
```

The `update_fields` argument lets `Mesh.save` skip the thumbnail-recompression
branch (per Task 10).

**Done when:** `generate_hover_preview.delay("<run_id>")` produces an animated
WebP under 300 KB and `Mesh.hover_preview_generated_at` is updated.

from django.contrib.gis.geoip2 import GeoIP2, GeoIP2Exception

def _client_ip(request):
    fwd = request.META.get("HTTP_X_FORWARDED_FOR", "")
    if fwd:
        return fwd.split(",")[0].strip()
    return request.META.get("REMOTE_ADDR", "")


@api_view(["GET"])
@permission_classes([AllowAny])
def geo_me(request):
    """Return a best-effort city/state/lat/lng for the requesting IP."""
    ip = _client_ip(request)
    if not ip or ip.startswith(("127.", "10.", "192.168.", "172.16.")):
        return Response({"source": "unknown",
                         "country": None, "state": None,
                         "lat": None, "lng": None})

    try:
        g = GeoIP2()
        city = g.city(ip)
    except (GeoIP2Exception, Exception):
        # Fallback to country-level if City DB isn't installed.
        try:
            country = g.country(ip)
            return Response({"source": "ip-country", "country": country.get("country_name"),
                             "state": None, "lat": None, "lng": None})
        except Exception:
            return Response({"source": "unknown",
                             "country": None, "state": None,
                             "lat": None, "lng": None})

    return Response({
        "source":  "ip-city",
        "country": city.get("country_name"),
        "state":   city.get("region_name") or city.get("region"),
        "city":    city.get("city"),
        "lat":     city.get("latitude"),
        "lng":     city.get("longitude"),
    })

#### Frontend — `services/geo.service.js`

```js
import { getApiBaseUrl } from '../utils/apiConfig';

const SESSION_KEY = 'tirtha_geo_v1';

export async function fetchIpGeo(signal) {
  // Single network roundtrip per session — cache in sessionStorage
  const cached = sessionStorage.getItem(SESSION_KEY);
  if (cached) {
    try { return JSON.parse(cached); } catch { /* fall through */ }
  }
  const r = await fetch(`${getApiBaseUrl()}/api/geo/me/`, { signal, credentials: 'omit' });
  if (!r.ok) return null;
  const data = await r.json();
  sessionStorage.setItem(SESSION_KEY, JSON.stringify(data));
  return data;
}

export function requestBrowserGeo(options = {}) {
  if (typeof navigator === 'undefined' || !navigator.geolocation) {
    return Promise.reject(new Error('Geolocation API unavailable'));
  }
  return new Promise((resolve, reject) => {
    navigator.geolocation.getCurrentPosition(
      (pos) => resolve({
        source: 'browser',
        lat:    pos.coords.latitude,
        lng:    pos.coords.longitude,
        accuracy: pos.coords.accuracy,
      }),
      (err) => reject(err),
      { timeout: 8000, maximumAge: 300_000, enableHighAccuracy: false, ...options },
    );
  });
}
```

import { fetchIpGeo, requestBrowserGeo } from '../services/geo.service';

function UserGeoFlyTo() {
  const map = useMap();
  const [didFly, setDidFly] = useState(false);

  useEffect(() => {
    if (didFly) return;
    let cancelled = false;
    (async () => {
      const geo = await fetchIpGeo().catch(() => null);
      if (cancelled || !geo?.lat || !geo?.lng || didFly) return;
      // Don't override if user already dragged/zoomed
      if (map._userInteracted) return;
      // State-level zoom (~6) is enough to see neighboring sites without losing context
      map.flyTo([geo.lat, geo.lng], 6, { animate: true, duration: 1.2 });
      setDidFly(true);
    })();
    return () => { cancelled = true; };
  }, [map, didFly]);

  // Cancel auto-fly if the user touches the map first
  useMapEvents({
    dragstart: () => { map._userInteracted = true; },
    zoomstart: () => { map._userInteracted = true; },
  });

  return null;
}

### Task 76 — Frontend NSFW pre-check via NSFWJS

**Files:** `frontend/package.json`,
`frontend/src/utils/imageValidation.js`,
`frontend/src/utils/nsfwClassifier.js` (new),
`frontend/src/components/ContributeModal.jsx` (UX touch-ups only)
**Depends on:** Task 41
**Goal:** Catch obvious NSFW uploads in the browser before they hit the
network, give immediate UX feedback. The existing server-side NSFW check
(`tirtha/nn_models/nsfw_model/` MobileNetV2 referenced in
`local_settings.docker.py:181`, executed by `imageops.py` as part of
`post_save_contrib_imageops`) remains the authoritative gate; the frontend
check is bandwidth-saving and UX, not enforcement.

#### Library

[NSFWJS](https://github.com/infinitered/nsfwjs) is a TensorFlow.js wrapper
around MobileNetV2 trained for the five categories `Drawing`, `Hentai`,
`Neutral`, `Porn`, `Sexy`. Runs entirely in the browser. Model size: ~4.5 MB
default; ~2.5 MB quantized.

#### Dependencies

`frontend/package.json`:
```
"nsfwjs":            "^4.2.1",
"@tensorflow/tfjs":  "^4.20.0"
```

These are sizable (~3 MB compressed combined). They must be lazy-loaded.

#### Lazy singleton classifier

`frontend/src/utils/nsfwClassifier.js`:
```js
// Lazy-loaded NSFW classifier. The TF.js + NSFWJS bundle (~3 MB gzipped) is
// only fetched when the user first opens the contribute modal and picks a file.

let modelPromise = null;

export function loadModel() {
  if (modelPromise) return modelPromise;
  modelPromise = (async () => {
    // Dynamic imports → Vite emits these as separate chunks (see vite.config.js).
    const [{ load }, tf] = await Promise.all([
      import('nsfwjs'),
      import('@tensorflow/tfjs'),
    ]);
    // WebGL is the default; CPU fallback is automatic if unavailable.
    await tf.setBackend('webgl').catch(() => tf.setBackend('cpu'));
    // 'MobileNetV2Mid' balances accuracy vs size; switch to 'MobileNetV2'
    // for the smaller quantized variant if bundle size becomes a concern.
    return load('/project/tirtha/static/nsfw-model/', { type: 'graph' });
    // Self-host the model at static/nsfw-model/ so prod CSP doesn't need
    // to allow nsfwjs.com. Vite copies it from frontend/public/nsfw-model/.
  })();
  return modelPromise;
}

const NSFW_THRESHOLDS = {
  invalid: 0.60,   // porn + hentai sum
  warning: 0.55,   // sexy
};

export async function classifyImage(htmlImageElement) {
  const model = await loadModel();
  const predictions = await model.classify(htmlImageElement);
  // Predictions are [{className, probability}], one per class.
  const by = Object.fromEntries(
    predictions.map((p) => [p.className.toLowerCase(), p.probability])
  );
  const explicit = (by.porn || 0) + (by.hentai || 0);
  const sexy     = by.sexy || 0;

  if (explicit >= NSFW_THRESHOLDS.invalid) {
    return {
      severity: 'invalid',
      reason: 'NSFW content detected. This image cannot be uploaded.',
      scores: by,
    };
  }
  if (sexy >= NSFW_THRESHOLDS.warning) {
    return {
      severity: 'warning',
      reason: 'Possibly suggestive content — admin will review.',
      scores: by,
    };
  }
  return { severity: 'valid', reason: '', scores: by };
}

export async function classifyFile(file) {
  // Loads the file into an offscreen Image, hands to the model, revokes URL.
  const url = URL.createObjectURL(file);
  try {
    const img = await new Promise((resolve, reject) => {
      const el = new Image();
      el.onload  = () => resolve(el);
      el.onerror = () => reject(new Error('image decode failed'));
      el.src     = url;
    });
    return await classifyImage(img);
  } finally {
    URL.revokeObjectURL(url);
  }
}
```

#### Self-host the model

NSFWJS by default fetches the model graph from `https://nsfwjs.com/...`. With
the CSP from Task 56, that's a cross-origin script source you don't want to
whitelist. Vendor the model into the repo:

1. Download the model files (`group1-shard*.bin`, `model.json`) from
   <https://github.com/infinitered/nsfwjs-model> for the MobileNetV2 variant.
2. Place them in `frontend/public/nsfw-model/`.
3. Vite copies `public/` into `dist/` at build time, so the production URL is
   `/project/tirtha/static/nsfw-model/model.json` (after `collectstatic`).
4. The `load(...)` call in `nsfwClassifier.js` points there.

#### Extend `imageValidation.js`

The existing `validateImageFile(file, {minDimension, warningDimension})`
returns `{severity, reason}` and is already called per file in
`ContributeModal.handleRawFiles` (`ContributeModal.jsx:258`). Compose NSFW on
top, preserving the worst severity:

```js
import { classifyFile } from './nsfwClassifier';

const SEVERITY_RANK = { valid: 0, warning: 1, invalid: 2 };
const worse = (a, b) => SEVERITY_RANK[a.severity] >= SEVERITY_RANK[b.severity] ? a : b;

export async function validateImageFile(file, opts = {}) {
  const basic = await runBasicChecks(file, opts);   // existing logic
  if (basic.severity === 'invalid') return basic;   // skip NSFW if already rejected

  // Skip NSFW for tiny files (probably non-photo assets) to save model load.
  if (file.size < 32 * 1024) return basic;

  let nsfw;
  try {
    nsfw = await classifyFile(file);
  } catch (err) {
    // Model failed to load (offline, blocked, etc.) — fall through to basic only.
    // Backend will still catch NSFW; this is a UX courtesy.
    return basic;
  }
  return worse(basic, nsfw);
}
```

(`runBasicChecks` is whatever the existing implementation does — extract its
body into a helper if it isn't already.)

#### Performance + size

- Model load is ~3 MB gzipped, fetched once per session, cached by the browser
  (and by the service worker in Task 71 once that ships).
- Inference: ~50–150 ms per 224×224 image on WebGL. For typical batches of
  10–50 photos, this is unnoticeable.
- WebGL fallback to CPU adds ~200 ms/image; still acceptable.
- Add to `vite.config.js` `manualChunks` so the bundle is isolated:
  ```js
  nsfw: ['nsfwjs', '@tensorflow/tfjs'],
  ```

#### Threshold tuning

The defaults (`porn+hentai > 0.6` invalid, `sexy > 0.55` warning) are
conservative for heritage / cultural-site photography (where ancient art,
nudity in stone carvings, etc., should NOT be rejected). After a week of
production data:

- Track the `scores` object in a `console.warn` for any image that gets a
  warning/invalid severity. Ask the admin to flag any obviously false
  positives.
- If the false-positive rate is high, raise the invalid threshold to 0.75 and
  the warning threshold to 0.65, OR exclude `hentai` from the explicit sum
  (some pose-heavy classical sculpture triggers the hentai class).

#### Honest caveats

- **Frontend NSFW is not a security boundary.** A motivated attacker disables
  JS, edits the bundle, or POSTs directly to `/api/contributions/upload/`.
  The server-side NSFW classifier in `nn_models/nsfw_model/` remains the
  authoritative check. This task is bandwidth-saving + instant UX.
- **False positives exist.** Carvings of Khajuraho, Konark, etc. (the
  exact use case for Tirtha) may be flagged. Surface a "Report false flag"
  link in the warning toast that pre-fills a contact form.

**Done when:**
- Opening the contribute modal triggers a one-time lazy load of the NSFW
  model (verify via DevTools → Network → see ~3 MB `nsfw` chunk).
- Selecting a clearly explicit test image shows an "Invalid: NSFW content
  detected" badge in the preview and excludes it from the upload count.
- A flagged image is *not* sent to `/api/contributions/upload/` (verify
  Network tab on submit).
- Loading the contribute modal offline still works — model load fails,
